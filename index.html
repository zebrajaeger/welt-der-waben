Einstellungen

Alle Raten gelten pro Simulationssekunde; 60 Ticks = 1 s. Änderungen werden erst durch Übernehmen aktiv. Dabei beginnt ein neuer Lauf.

Speichern bewahrt den Formularentwurf für spätere Besuche dieser Browseradresse. Standardwerte setzt das Formular zurück; anschließend übernehmen oder speichern.

JSON-Dateien übertragen nur Einstellungen. Export lädt den gültigen Formularentwurf herunter. Import ersetzt nur das Formular; anschließend übernehmen oder im Browser speichern. Die Datei bleibt auf diesem Gerät.
